# google-page-clone

A small frontend practice project: a minimal Google home page clone built to learn HTML and CSS.

Contents
- `src/index.html` — simple personal landing page
- `src/work.html` — the Google-style page (search input, logo, buttons)
- `src/styles.css` — styles for the project

How to view
1. Open `src/index.html` or `src/work.html` in your browser (double-click or use a local server).

Notes & suggestions
- This repository is intentionally minimal for learning. Consider adding a short development server (e.g., `npx http-server`), more semantic structure, and accessibility improvements.
